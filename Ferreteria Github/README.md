# Ferretería El Constructor

Versión de demostración visual para GitHub Pages.

Esta página muestra el diseño del sistema de facturación y permite recorrer las pantallas de administrador y vendedor. Incluye productos, clientes y facturas de ejemplo. No se conecta a SQL Server, no envía correos ni registra ventas reales.

Para abrir la demostración, entrá a `index.html` o al enlace de GitHub Pages del repositorio.

El sistema original con Node.js y SQL Server se ejecuta por separado en una computadora configurada para ello.
